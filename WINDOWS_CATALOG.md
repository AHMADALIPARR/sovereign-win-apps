Not every application ships with every Windows edition. Some are optional, deprecated, or require installation.

One important distinction: This is a catalog of major Windows applications and tools, not a literal enumeration of every Microsoft-shipped executable, DLL, service, optional feature, or packaged component. A truly exhaustive list would have thousands of entries and depend on the exact Windows build and edition.

This catalog is included for reference. Matching applications implemented in C against the win32sov SDK appear under apps/ (see README.md for the current set).
